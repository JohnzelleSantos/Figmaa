Fanteasy is a responsive website for a project that is fantasy themed tea cafe, built as my final requirement for Introduction to Web
Development. It's a project I've been interested in since senior high school, when I first got curious about turning a design idea into
a real, working website. The site has four pages (Home, About, Menu and Reservation) and adapts to mobile, tablet, desktop and print
layouts. It was built with HTML, CSS and JavaScript, and it let me practice responsive design, form validation and consistent visual
styling.
